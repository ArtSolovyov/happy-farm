# 🌻 Счастливая ферма

Простое 2D-демо фермы с видом сверху (Canvas 2D, TypeScript, Vite).

## Цель

Выращивай урожай и заработай **200 монет** — тогда ферма процветает (экран победы).

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | движение |
| E | вскопать → посадить → полить → собрать (контекстное) |
| 1 / 2 / 3 | выбор культуры (пшеница / морковь / тыква) |
| Q | купить семя выбранной культуры |
| Esc | пауза |
| M | звук вкл/выкл |
| Пробел | старт / рестарт |

## Основные системы

- Цикл грядки: трава → вскопана → посажена → (полита) → созрела → собрана
- Рост идёт **только пока почва влажная** (полив действует 25 с)
- Экономика семян: покупка за монеты, три культуры с разной ценой / сроком / прибылью
- Смена дня и ночи (100 с на день), солнце/луна в HUD
- Частицы, всплывающие цифры дохода, бабочки, звук и генеративная музыка (Web Audio)
- Рекорды в `localStorage` (только этот браузер; очистка данных браузера их сотрёт)

## Запуск

```bash
npm install
npm run dev        # дев-сервер
npm run build      # прод-сборка в dist/
node scripts/verify-game.mjs   # браузерная самопроверка сборки
```

## Техника

Фиксированный игровой шаг 60 Гц (`src/game/engine.ts`), состояния title/playing/paused/gameover
(`state.ts`), ввод с клавиатуры и тача (`input.ts`), пулинг частиц без аллокаций в горячем цикле,
детерминированный PRNG для декора. Вся графика рисуется кодом — внешних ассетов нет.
